# Оптимизация веб-приложений — домашние задания

Общий репозиторий для сдачи домашних заданий и лабораторных работ по дисциплине «Оптимизация веб-приложений». **Способ сдачи — этот репозиторий:** преподавателю отправляется ссылка на него. В папках лежат отчёты по работам — DOCX и PDF (в ЛР №4 к отчёту добавлено приложение с семантическим ядром в XLSX), а в корне — файлы опубликованных сайтов: они открываются на GitHub Pages, поэтому лежат не в папках. Что именно лежит в корне, описано в конце страницы.

**Студент:** Чеголин Алексей Михайлович  
**Группа:** 4ИСИП-923  
**Преподаватель:** Рыбаков А.С.
