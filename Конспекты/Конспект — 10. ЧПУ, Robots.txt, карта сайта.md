# Конспект — 10. ЧПУ, Robots.txt, карта сайта

> Тема занятия из [таблицы курса](https://docs.google.com/spreadsheets/d/1mLdR4r9jjsBcKdaG77887BA6OdZc_tCmDNlfhJGdJfk/edit?gid=187801412). Связанное ДЗ — анализ robots.txt для приюта «Солнцево»; ЛР — ЛР №3 — Структура сайта и карта сайта (sitemap.xml).

## 1. ЧПУ (человекопонятный URL)

**ЧПУ (CNC / Human-readable URL)** — адрес страницы, понятный человеку, без `?id=123&cat=45`.

| Плохой URL | ЧПУ |
|-----------|-----|
| `/product.php?id=4821&cat=12` | `/telefony/smartfony/xiaomi-redmi-12/` |
| `/index.php?route=news/item&nid=77` | `/news/otkrytie-novogo-sklada/` |

### Правила ЧПУ

1. Слова вместо идентификаторов: `/remont-kvartir/`, не `/usluga_45/`
2. Строчные буквы, дефисы `-` между словами (не `_`)
3. Без параметров сессии в URL
4. Латиница/кириллица — по стандарту; кириллица правильно кодируется
5. Длина: короткий, читаемый, ≤ страницы-каталога
6. Одна страница = один URL (иначе дубли — см. [Конспект — 11-12. Устранение технических ошибок](%D0%9A%D0%BE%D0%BD%D1%81%D0%BF%D0%B5%D0%BA%D1%82%20%E2%80%94%2011-12.%20%D0%A3%D1%81%D1%82%D1%80%D0%B0%D0%BD%D0%B5%D0%BD%D0%B8%D0%B5%20%D1%82%D0%B5%D1%85%D0%BD%D0%B8%D1%87%D0%B5%D1%81%D0%BA%D0%B8%D1%85%20%D0%BE%D1%88%D0%B8%D0%B1%D0%BE%D0%BA.md))

### Зачем

- Пользователь понимает, куда попадёт (доверие, удобство)
- Ссылка читается в сниппете и выглядит надёжнее → выше CTR
- По ключевым словам в URL — фактор ранжирования
- URL легко переслать, он говорит за себя

## 2. robots.txt

Файл в корне сайта: `/robots.txt`. Содержит правила для поисковых роботов: что индексировать, что нет. **Не является файлом безопасности** — всё, что в нём закрыто, роботу «не стоит», а не «нельзя».

### Синтаксис

```txt
User-agent: *          # правила для всех роботов
Disallow: /admin/      # закрыть служебный раздел
Disallow: /cart/       # корзина
Disallow: /*?sort=     # wildcard: параметры сортировки
Allow: /cart/checkout  # но эту страницу открыть
Crawl-delay: 10        # пауза между запросами (для тяжёлых сайтов)

User-agent: Yandex     # отдельные правила для Яндекса
Disallow: /private/

Sitemap: https://site.ru/sitemap.xml
Clean-param: utm_source&utm_medium https://site.ru/  # параметры-мусор
```

### Частые ошибки

- `Disallow: /` — закрывает сайт целиком (печально после переноса)
- Закрытие `/css/`, `/js/` — робот не видит стили и scripts → проблемы с индексированием
- Забытый `Allow` под намеренно закрытый раздел
- Отсутствие `Sitemap:` — робот будет дольше находить sitemap

### robots vs noindex

- `robots.txt: Disallow` — робот не заходит на страницу (не читает и `noindex` внутри!)
- `<meta name="robots" content="noindex">` — страница читается, но не попадает в индекс
- `X-Robots-Tag: noindex` — то же для не-HTML (PDF, картинки)

**Правило:** страницы-дубли с именами в индексе → закрывают meta noindex; служебные и дубли — `Disallow`.

## 3. sitemap.xml

Карта сайта для роботов: список URL с метаданными (дата изменения, частота, приоритет).

```xml
<?xml version="1.0" encoding="UTF-8"?>
<urlset xmlns="http://www.sitemaps.org/schemas/sitemap/0.9">
  <url>
    <loc>https://site.ru/telefony/xiaomi/</loc>
    <lastmod>2026-10-08</lastmod>
    <changefreq>weekly</changefreq>
    <priority>0.8</priority>
  </url>
</urlset>
```

- Лимит: 50 000 URL или 50 МБ на файл; дальше — индексные sitemap (`<sitemapindex>`)
- Разместить в `robots.txt` и в Вебмастере/Search Console
- Доступность для гостей: закрытый в `Disallow` sitemap не имеет смысла

## Порядок работы (по практике курса)

1. Составить список адресов сайта (если нет карты)
2. Сгенерировать `sitemap.xml` (вручную или CMS/плагином)
3. Написать `robots.txt` с правилами и указанием sitemap
4. Проверить валидатором (например, XML-валидатор)
5. Добавить в Яндекс.Вебмастер и Google Search Console
6. Контроль индексации через поиск (site:, «проверка ответа сервера»)

## Термины

| Термин | Определение |
|--------|-------------|
| ЧПУ | Человекопонятный URL без технических параметров |
| Robots.txt | Файл правил индексирования для поисковых роботов |
| Sitemap.xml | XML-карта сайта: список URL с метаданными |
| noindex | Метатег/заголовок: страницу не включать в индекс |
| User-agent | Идентификатор робота (`*` — все) |
| Clean-param | Директива Яндекса: игнорировать лишние параметры URL |
