# Конспект — 2. SEO — что это такое

> Тема занятия из [таблицы курса](https://docs.google.com/spreadsheets/d/1mLdR4r9jjsBcKdaG77887BA6OdZc_tCmDNlfhJGdJfk/edit?gid=187801412). Связанное ДЗ — «Анализ по запросам» (анализ поисковой выдачи).

## Определение

**SEO (Search Engine Optimization)** — комплекс мероприятий, направленных на повышение позиций сайта в результатах поисковой системы по некоторому списку запросов.

Не «обман поисковика», а адаптация сайта под то, что считает качественным сам поисковик, + удобство для людей.

## Структура поисковой выдачи

На странице результатов поиска (SERP) блоки: бесплатные сниппеты, контекстная реклама сверху/снизу, товары, изображения, карта. Выше 3–4 позиции — основная доля кликов: цель SEO — попадание в топ-10, а лучше в топ-3.

**Сниппет** — блок ссылки в выдаче: заголовок, описание, URL. Управляется через title, description и контент страницы (см. [Конспект — 15. Повышение релевантности](%D0%9A%D0%BE%D0%BD%D1%81%D0%BF%D0%B5%D0%BA%D1%82%20%E2%80%94%2015.%20%D0%9F%D0%BE%D0%B2%D1%8B%D1%88%D0%B5%D0%BD%D0%B8%D0%B5%20%D1%80%D0%B5%D0%BB%D0%B5%D0%B2%D0%B0%D0%BD%D1%82%D0%BD%D0%BE%D1%81%D1%82%D0%B8.md)).

## Как работает поисковая система

1. **Краулинг** — поисковый робот обходит страницы сайта по ссылкам
2. **Индексирование** — страницы попадают в индекс поисковика
3. **Ранжирование** — по алгоритму ищутся документы, релевантные запросу
4. **Выдача** — сортировка по сотням факторов (релевантность, авторитетность, поведение, скорость, безопасность)

## Три направления SEO

| Направление | Что решает |
|-------------|------------|
| **Внутренняя оптимизация** | Title, description, заголовки H1–H6, тексты, перелинковка, ЧПУ, микроразметка |
| **Внешняя оптимизация** | Ссылки с других сайтов (с тематическими, качественными доменами), упоминания |
| **Техническая оптимизация** | Индексация: robots.txt, sitemap.xml, дубли, битые ссылки, ЧПУ, скорость загрузки |

Поведческие факторы и юзабилити усиливают всё: зачем топ-3, если посетитель сразу уходит.

## Три метода продвижения

- **Белое SEO** — легальные методы внутри поисковых правил: качественный контент, корректная оптимизация, работа с поведением. Долго, но стабильно.
- **Чёрное SEO** — запрещённые методы: дорвеи, клоакинг, скрытый текст, линкопомойки, авто-сети. Даёт быстрый эффект, потом фильтры/бан.
- **Серое SEO** — смешанные/пограничные методы.

Google и Яндекс публикуют требования и применяют алгоритмы против некачественных ссылок/контента (Google Penguin, BERT; Яндекс Баден-Баден и др.). Санкции — тема отдельного занятия (см. таблицу курса).

## Факторы ранжирования (группы)

| Группа факторов | Примеры |
|-----------------|---------|
| Внутренние | Title, description, H1, тексты, ЧПУ, перелинковка |
| Внешние | Ссылочная масса, авторитетность доноров |
| Поведенческие | Время на сайте, глубина, CTR сниппета |
| Коммерческие | Наличие цен, контактов, корзины, отзывов |
| Технические | Скорость, мобильная адаптивность, безопасность (HTTPS) |

Можно пользоваться статистикой: [сервисы анализа ключей](#) Wordstat/Яндекс.Вебмастер, Key Collector.

## Метрики SEO

| Метрика | Значение |
|---------|----------|
| Позиция | Место по конкретному запросу |
| Видимость (ИКС) | Индекс качества сайта Яндекса, ~ полезнее тИЦ |
| Объём трафика из поиска | Количество посетителей из выдачи |
| CTR | Доля кликов по сниппету |
| Конверсия из поиска | Доля целевых действий |

## Термины

| Термин | Определение |
|--------|-------------|
| SEO | Поисковая оптимизация: рост позиций в выдаче |
| SERP | Страница результатов поиска |
| Сниппет | Блок ссылки в выдаче (title+description+URL) |
| Краулинг | Обход страниц поисковым роботом |
| Индекс | База документов поисковика |
| Ранжирование | Расстановка документов по релевантности |
| Дорвей | Страница под робота с мусорным контентом (чёрное SEO) |
| Клоакинг | Показ роботу и пользователю разного контента (запрещено) |
