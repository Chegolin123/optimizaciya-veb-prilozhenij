# Конспект — 4. Юзабилити-аудит

> Источник: презентация занятия (Рыбаков, <https://disk.yandex.ru/i/jdRKsmtBivVdhg>), локально — `_Материалы/4_Юзабилити-аудит.pptx` (22 слайда).

## Что такое юзабилити и аудит

**Юзабилити** — степень, с которой сайт может быть использован конкретными пользователями для достижения конкретных целей в конкретном контексте с должной эффективностью, продуктивностью и удовлетворённостью.

**Юзабилити-аудит** — экспертный анализ существующего интерфейса (или прототипа), выявляющий проблемы, возникающие у пользователя при взаимодействии с сайтом.

## Характеристики юзабилити

| Характеристика | Вопрос |
|----------------|--------|
| Время достижения цели | Сколько пользователю нужно, чтобы сделать заказ? |
| Ошибки | Где пользователи «спотыкаются»? |
| Скорость обучения | Поймёт ли новый посетитель, как пользоваться? |
| Запоминаемость | Вернувшись через месяц, снова ли он легко ориентируется? |
| Удовлетворённость | Приятно ли пользоваться? |

## Что даёт качественный аудит

- Увеличение дохода за счёт улучшения сайта
- Видимость точек падения конверсии — почему клиенты уходят
- Список проблем с приоритетами и рекомендации
- План развития сайта
- Сокращение числа ушедших без покупки

**Конверсия** — доля визитов, в ходе которых посетитель совершил целевое действие.

## Этапы юзабилити-аудита

1. **Внутрикорпоративное исследование и анализ статистики** — поведение пользователей на сайте
2. **Описание кластеров целевой аудитории, целей и потребностей** — «персонажи» (персоны)
3. **Разработка сценариев для юзабилити-аудита** — пользовательские сценарии для проверки

### Описание персонажа включает

- Цели персонажа
- Потребности
- Социальное положение
- Описание рабочего процесса
- Описание окружения
- Уровень знаний в предметной области
- Неудовлетворённости и ожидания
- Личная история

Примеры персонажей из кейсов: Росгосцирк, НоваКид, Лаборкомплект.

### Пример сценариев для интернет-магазина

1. Первое знакомство с сайтом
2. Поиск определённого товара
3. Поиск товара по заданным критериям
4. Принятие решения о покупке именно в этом магазине
5. Выяснение условий оплаты и доставки до оформления заказа
6. Оформление заказа
7. Положительный отзыв после покупки

## Методики оценки качества юзабилити

| Методика | Суть |
|----------|------|
| Heuristic Evaluation (эвристическая оценка) | Эксперт проверяет интерфейс на соответствие принципам юзабилити (Нильсен) |
| Heuristic Estimation | Сравнивают удобство двух+ вариантов дизайна |
| Cognitive Walkthrough | Разбивка всех задач пользователя на шаги и анализ каждого шага |
| Pluralistic Walkthrough | Групповой Cognitive Walkthrough (эксперты + пользователи) |
| Feature Inspection | Проверка слишком длинных последовательностей на предмет сокращения |
| Consistency Inspection | Обнаружение схожих разделов и ошибок непоследовательности |
| Standards Inspection | Соответствие интерфейса стандартам пользовательского интерфейса |
| Formal Usability Inspection | Поиск слабых мест, где теряется производительность работы пользователя |

## Плюсы и минусы аудита

**Плюсы:** проводится быстро (быстрый вариант — 7–8 дней); относительно бюджетная цена по сравнению с юзабилити-тестированием; высокая детализация результатов; не требует специального оборудования и сервисов.

**Минусы:** качество напрямую зависит от подготовки эксперта; для проверки гипотез приходится привлекать реальных пользователей.

## Термины

| Термин | Определение |
|--------|-------------|
| Юзабилити | Степень удобства использования продукта для достижения целей пользователей |
| Юзабилити-аудит | Экспертный анализ интерфейса на предмет проблем пользователей |
| Конверсия | Доля визитов с целевым действием |
| Персонаж (персона) | Описание типажного пользователя: цели, контекст, барьеры |
| Эвристическая оценка | Аудит по совокупности принципов (эвристик) |
| Юзабилити-тестирование | Наблюдение за реальными пользователями при выполнении задач |
