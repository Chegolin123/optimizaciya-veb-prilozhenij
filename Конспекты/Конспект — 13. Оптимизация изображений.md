# Конспект — 13. Оптимизация изображений

> Тема занятия из [таблицы курса](https://docs.google.com/spreadsheets/d/1mLdR4r9jjsBcKdaG77887BA6OdZc_tCmDNlfhJGdJfk/edit?gid=187801412). Связанная работа: Практическая работа 2-3 (29.09.2026) — ЛР: 1,53 МБ → 197,9 кБ при тех же 3840×2400.

## Зачем оптимизировать изображения

Изображения — **самый тяжёлый ресурс** страницы: на фотогалерее и в каталоге товаров они дают 60–80% веса страницы. Сжатие = быстрее LCP → лучше поведенческие факторы и позиции.

## Форматы

| Формат | Когда | Потери |
|--------|-------|--------|
| JPEG | Фото, градиенты | С потерями, настраиваемое качество |
| PNG | Скриншоты, графика с прозрачностью | Без потерь, тяжёлый |
| WebP | Универсальный (фото + графика) | −25–35% к JPEG/PNG при том же качестве |
| AVIF | Современная замена WebP | −20–30% к WebP; поддержка немного уже |
| SVG | Иконки, логотипы | Вектор, крошечный, масштабируется |
| GIF | Только простая анимация | Устаревший; заменять на видео WebP/MP4 |

**Правило:** фото — JPEG/WebP; графика и скриншоты — PNG/SVG; всё новое — WebP/AVIF с fallback.

## Сжатие: с потерями и без

- **С потерями (lossy)** — выбрасывает часть данных: 80% качества JPEG/WebP неотличимо для глаза. Основной инструмент.
- **Без потерь (lossless)** — убирает метаданные и избыточность: PNG → −10–20% без потери качества.
- **Метаданные:** EXIF, миниатюры, ICC — у товарных картинок почти всегда лишние (кроме авторских прав); удалять. Но: **не удалять EXIF с геометками в evidence** — в фото-отчётах они служат доказательством (наш кейс курсовой!).

## Размеры и ресемплинг

Ошибка: `3840×2400` оригинал выводится в `384×240` блок — браузер масштабирует, но **качает полный файл**. Нужны thumbnails:

```
products/redmi-12/
├── original.jpg      # 3840×2400, только для скачивания
├── card.jpg          # 600×375 — карточка каталога
├── preview.jpg       # 300×188 — миниатюра
└── thumb.jpg         # 100×63 — корзина/похожие
```

Плотность пикселей: для Retina-ready картинку делают в 2× от выводимого размера.

## Способы отдачи браузеру

```html
<!-- Адаптивные размеры: браузер выбирает файл сам -->
<img src="card.jpg"
     srcset="card.jpg 1x, card@2x.jpg 2x"
     sizes="(max-width: 600px) 100vw, 600px"
     alt="Смартфон Xiaomi Redmi 12, синий">

<!-- Выбор формата -->
<picture>
  <source srcset="photo.avif" type="image/avif">
  <source srcset="photo.webp" type="image/webp">
  <img src="photo.jpg" alt="...">
</picture>

<!-- Ленивая загрузка: ниже сгиба — грузим при скролле -->
<img src="preview.jpg" loading="lazy" alt="...">
<!-- Первое изображение (LCP) — БЕЗ lazy, оно должно грузиться сразу -->
```

- **`loading="lazy"`** для всех, кроме первого экрана — там ленивая загрузка вредит LCP
- **Атрибут `width`/`height`** у `<img>` резервирует место → не «прыгает» вёрстка (CLS)
- **CSS-background** с изображением не ловит `lazy` — использовать `<img>` вместо div с background, когда важно
- **Иконочные спрайты** — один файл вместо 30 иконок

## Инструменты

| Инструмент | Что делает |
|------------|------------|
| Squoosh (веб) | Ручное сжатие с превью «до/после» |
| TinyPNG / TinyJPG | Lossy/lossless, API |
| ImageMagick (`convert`, `mogrify`) | Пакетная обработка: resize, quality, strip |
| `cwebp` / `avifenc` | Конвертация в современные форматы |
| Плагины CMS | Автосжатие при загрузке, генерация размеров |
| Gulp/Webpack (`imagemin`) | Оптимизация в сборке |

Пример пакетовой обработки (наш кейс ЛР):

```bash
magick original.jpg -resize 600x375 -quality 82 -strip card.jpg
# 1,53 МБ → ~200 КБ при визуально одинаковом качестве
```

## Оптимизация на уровне сервера

- Отдавать WebP тем браузерам, которые его поддерживают (content negotiation)
- CDN с оптимизацией on-the-fly (Cloudflare Images, Cloudinary)
- Кэш: `Cache-Control: max-age=31536000` на `/images/`
- Не отдавать 404-заглушки как картинки (исключение: onerror placeholder)

## Термины

| Термин | Определение |
|--------|-------------|
| Lossy | Сжатие с потерями: часть данных выбрасывается |
| Lossless | Сжатие без потерь: убирается избыточность |
| Reсемплинг | Уменьшение пиксельных размеров изображения |
| srcset/sizes | Атрибуты выбора картинки под экран/плотность |
| Lazy loading | Отложенная загрузка изображений вне экрана |
| AVIF | Современный формат с максимальным сжатием |
| Иконочный спрайт | Один файл со множеством иконок |
