## Зачем классифицировать сайты

Тип сайта определяет: структуру, функционал, выбор CMS, методы продвижения и метрики успеха. Классификатор из лекции — 7 групп.

## Классификация (по лекции)

### 1. Личный сайт

| Подвид | Суть |
|--------|------|
| Небольшая личная страница | Несколько страниц, объединены личностью/интересами автора |
| Расширенная личная страница | + архив статей, форум, чат |
| Коммерческий личный сайт | Частные предприниматели, предлагающие услуги |

### 2. Бизнес-сайт

| Подвид | Суть |
|--------|------|
| Сайт-визитка | 1–5 страниц, сведения о компании, контакты, прайс на скачивание |
| Бизнес-сайт МСБ | Детальный ассортимент продукции/услуг, + форум, лента новостей, голосования |
| Крупный бизнес-сайт | Много разделов: продукция, аналитика, законодательство, вакансии |
| Внутренний (интранет) | Виртуальный офис: единая система обмена, хранения, обработки информации для удалённых сотрудников |
| Промо-сайт | Временный, информирующий: акции, выставки |

### 3. Сайты электронной коммерции

- **Интернет-магазин** — каталог, корзина, оформление заказа
- **Интернет-магазин с электронными платежами** — оплата онлайн
- **Обменные пункты** — обмен электронной валюты

### 4. Информационные порталы

- **Новостной портал** — новости в реальном времени
- **Тематический портал** — узкая тематика
- **Доски объявлений** — avito.ru
- **Файловые архивы** — статьи, ПО
- **Wiki** — содержание и структуру редактируют сами посетители (Википедия)

### 5. Интернет-общение

- **Форум** — общение по темам
- **Блоги** — виртуальный дневник: записи, комментарии, друзья, закладки
- **Чаты** — общение в реальном времени

### 6. Сайты специального назначения

- **WAP-сайт** — для мобильных телефонов (язык WML)
- **Поисковая система** — поиск информации по запросу
- **Каталоги и рубрикаторы** — систематизированный перечень сайтов/компаний/товаров (общетематические, тематические, специализированные)
- **Рейтинги сайтов, системы статистики** — упорядочивание по показателям (переходы, посетители)
- **Почтовые сайты** — почтовый ящик и управление им

### 7. Коммерческие личные сайты (дополнительно)

Используются частными предпринимателями: портфолио услуг, прайс, контакты.

## Что это даёт для оптимизации (связь с курсом)

- Тип сайта → **семантическое ядро** (см. [Конспект — 15. Повышение релевантности](%D0%9A%D0%BE%D0%BD%D1%81%D0%BF%D0%B5%D0%BA%D1%82%20%E2%80%94%2015.%20%D0%9F%D0%BE%D0%B2%D1%8B%D1%88%D0%B5%D0%BD%D0%B8%D0%B5%20%D1%80%D0%B5%D0%BB%D0%B5%D0%B2%D0%B0%D0%BD%D1%82%D0%BD%D0%BE%D1%81%D1%82%D0%B8.md) и ЛР №4 — Семантическое ядро и вёрстка сайта (FoodGo)): у магазина — коммерческие запросы, у портала — информационные
- Тип сайта → метрики: для визитки — звонки/заявки, для магазина — конверсия в заказ
- Тип сайта → набор технических требований: sitemap.xml и robots.txt одинаково нужны всем, но глубина перелинковки и ЧПУ-структура отличаются

## Термины

| Термин | Определение |
|--------|-------------|
| Сайт-визитка | Небольшой бизнес-сайт (1–5 страниц) с контактами и прайсом |
| Промо-сайт | Временный сайт под акцию/продукт/мероприятие |
| Интранет | Внутренний корпоративный сайт для сотрудников |
| WAP-сайт | Сайт для мобильных телефонов на языке WML |
| Wiki | Сайт, который редактируют сами посетители |
