# Конспект — 1.1. Основы разработки web-приложения

> Источник: презентация занятия «Web-разработка» (Рыбаков, <https://disk.yandex.ru/i/SINFFChAJFH5Dg>), локально — `_Материалы/1-1_Основы-разработки-web-приложения.pptx` (70 слайдов).

## Web-приложение — определение

**Web-приложение** — приложение, разработанное по архитектуре «клиент-сервер», где клиентом является веб-браузер, а работа идёт по протоколу HTTP на стороне веб-сервера.

Примеры: поисковики, энциклопедии, видеохостинги, новостные сайты, интернет-магазины, соцсети, онлайн-сервисы (погода, бухгалтерия, обработка фото, покупка билетов).

## Инструменты разработки

**HTML-редакторы:**
- *Текстовые* — работают напрямую с HTML-кодом: HTMLPad, Notepad
- *Специализированные* — автоматизируют разработку по принципу WYSIWYG: MS FrontPage, DreamWeaver, Corel Website Creator, StudioLine Web, HomeSite

**Графика и анимация:** Adobe Photoshop, Macromedia Fireworks/FreeHand/Flash.

## Языки разработки

| Язык | Роль |
|------|------|
| HTML | язык разметки гипертекста |
| PHP | серверные скрипты |
| JavaScript | интерактивность HTML-документов |
| Perl | CGI-сценарии, обработка почты, поддержка web-узлов |
| Java | серверные/корпоративные приложения |

## Веб-стандарты

Открытые спецификации и рекомендации **W3C** (Консорциум Всемирной паутины). **WaSP** (Web Standards Project) — добровольная организация, пропагандирующая стандарты.

Причины использования стандартов: эффективность кода, лёгкость сопровождения, совместимость с устройствами, корректная работа поисковых роботов.

## Этапы разработки сайта

1. **Подготовительный** — цель сайта, целевая аудитория, ожидаемая информация, выбор ПО, планирование навигации
2. **Разработка макета** — графическое представление дизайна (PSD со слоями или JPEG/PNG)
3. **Вёрстка** — HTML + CSS
4. **Программирование / установка на CMS**
5. **Наполнение контентом** — SEO-копирайтинг (тексты и под пользователя, и под поисковики)
6. **Публикация** — домен + хостинг, регистрация в поисковиках
7. **Раскрутка**
8. **Администрирование (поддержка)**

**Техническое задание** — документ с типом сайта, функционалом, стилем дизайна, структурой сайта и страниц.

## Верстка: требования и виды

Требования: кроссбраузерность, гибкость, быстрота обработки кода браузером, валидность, семантическая корректность.

**Табличная:** простая, одинаковая в браузерах, но долгая загрузка, громоздкий код, плохая индексация, смешение содержания и оформления, не соответствует стандартам.

**Блочная:** компактный код, быстрая загрузка, отличная индексация, слои накладываются друг на друга; но сложнее в разработке и труднее добиться одинакового вида во всех браузерах.

По ширине: **фиксированная** (пиксели — дизайн до пикселя, ломается на других разрешениях), **резиновая** (проценты — адаптируется под монитор, но дизайн «плывёт»), **гибридная** (смешанные размеры).

## CMS

**CMS (Content Management System)** — система управления сайтом: платформа для создания и поддержки сайтов. Виды: бесплатные (Joomla, WordPress, MODx) и платные. Качественные CMS требуют актуальный PHP и MySQL. Каталог CMS: cmsmagazine.ru.

## Публикация: домены и хостинг

**Доменное имя** — уникальный адрес ресурса в сети. Уровни: `.com` → `google.com` → `rabota.google.com`. Распределением DNS занимается IANA, регистрация — через регистраторы (Рег.ру, Rusonyx, Джино).

Правила: домен свободен, соответствует теме, короткий и запоминающийся, один владелец.

**Хостинг** — предоставление дискового пространства на постоянно работающем сервере.

| Критерий | Виды |
|----------|------|
| Стоимость | платный / бесплатный (реклама, мало места, низкая надёжность, медленно) |
| Расположение | российский, украинский, американский и т.д. |
| ПО | UNIX-хостинг / WINDOWS-хостинг |
| Тип сервера | виртуальный, виртуальный выделенный (VDS), выделенный, co-location |

Co-location: свой сервер на площадке провайдера, провайдер следит за питанием и каналами.

Факторы выбора: теххарактеристики, загруженность канала, поддержка, доступность 24/7, перечень услуг, объём трафика, цена без скрытых платежей.

## Раскрутка: методы и тИЦ

Бесплатные методы: регистрация в ПС, работа над контентом, почтовая рассылка, каталоги и рейтинги, обмен текстовыми ссылками, баннерные сети, доски объявлений, чужие рассылки, СМИ, обмен ссылками с тематическими сайтами, форумы.

**SEO** — комплекс мероприятий по повышению позиций сайта в поисковой выдаче по запросам.

**тИЦ** — тематический индекс цитирования Яндекса: авторитетность ресурса с учётом качества ссылок и тематической близости ссылающихся сайтов; влияет на порядок в рубриках каталога.

Поддержка сайта — обновление самостоятельно или специалистами на платной основе.

## Термины

| Термин | Определение |
|--------|-------------|
| Web-приложение | Клиент-серверное приложение с браузером в роли клиента, работает по HTTP |
| WYSIWYG | What You See Is What You Get — редактор с визуальным редактированием |
| Валидность | Соответствие кода стандартам (W3C) |
| Семантическая вёрстка | Логичное использование HTML-элементов по смыслу |
| CMS | Система управления контентом (движок сайта) |
| ТЗ | Документ с требованиями к будущему сайту |
| Co-location | Размещение своего сервера на площадке хостинг-провайдера |
| тИЦ | Тематический индекс цитирования Яндекса |
