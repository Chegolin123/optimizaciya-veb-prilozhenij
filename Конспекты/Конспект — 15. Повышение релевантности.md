# Конспект — 15. Повышение релевантности

> Тема занятия из [таблицы курса](https://docs.google.com/spreadsheets/d/1mLdR4r9jjsBcKdaG77887BA6OdZc_tCmDNlfhJGdJfk/edit?gid=187801412). Связанные работы: ЛР №4 — Семантическое ядро и вёрстка сайта (FoodGo), ПР 5 «Сниппеты, SEO-теги и семантическая разметка».

## Что такое релевантность

**Релевантность** — соответствие страницы поисковому запросу пользователя. Задача SEO: по каждому запросу показывать пользователю максимально подходящую страницу — и добиваться, чтобы это была страница нужного сайта.

Релевантность = связность «запрос → страница» по нескольким факторам: наличие слов в тексте, title, заголовках, URL, ссылках, поведение посетителей (кликают ли, остаются ли).

## Анатомия сниппета

| Элемент | Где задаётся | Что делает |
|---------|--------------|------------|
| Заголовок | `<title>` | Первая строка выдачи — главный фактор клика |
| Описание | `<meta name="description">` | Серый текст под заголовком |
| URL | адрес страницы | Читаемость + ключи (см. [Конспект — 10. ЧПУ, Robots.txt, карта сайта](%D0%9A%D0%BE%D0%BD%D1%81%D0%BF%D0%B5%D0%BA%D1%82%20%E2%80%94%2010.%20%D0%A7%D0%9F%D0%A3%2C%20Robots.txt%2C%20%D0%BA%D0%B0%D1%80%D1%82%D0%B0%20%D1%81%D0%B0%D0%B9%D1%82%D0%B0.md)) |
| Быстрые ссылки | разметка, структура | Дополнительные пункты под ссылкой |
| Дата, рейтинг | разметка schema.org | Звёздочки, цена, наличие |

**Заголовок (title) должен:** содержать главный ключ как можно левее, быть ≤ 60–70 символов, отличаться от title других страниц, вызывать клик.

**Description:** 120–160 символов, содержит ключ и призыв к действию; поисковик может подставить свой вариант из текста — но при качестве описания он чаще использует авторский.

## Три типа ключей и структура страниц

| Тип запроса | Что ищет пользователь | Страница должна содержать |
|-------------|----------------------|---------------------------|
| Информационный | Ответ, инструкция | Текст, ответ в начале, изображения |
| Коммерческий | Купить, цена, сравнение | Цена, наличие, корзина, условия доставки |
| Навигационный | Конкретный сайт/бренд | Название, контакты, вход |

**Правило «1 страница = 1 кластер запросов»:** страница про «смартфоны Xiaomi» не должна конкурировать со страницей «смартфоны Samsung». Конкуренция собственных страниц за один запрос = каннибализация → обе ранжируются хуже.

## Внутренние факторы релевантности

1. **Title** с главным ключом
2. **H1** — один на страницу, близок к title
3. **H2–H6** — подзаголовки с дополнительными ключами
4. **Первые абзацы текста** — ключ в первых 100–150 словах
5. **URL** — ключ словами через дефис
6. **alt изображений** — описание с ключом (но не переспам)
7. **Перелинковка** — ссылки с релевантных страниц с анкорами
8. **Семантическое ядро** — слова рядом с ключом (LSI): «доставка», «цена», «отзывы» для товара
9. **Длина текста** — не «норма символов», а полнота ответа

## Внешние факторы

- Ссылки с тематических страниц с нужным анкором (см. [Конспект — 2. SEO — что это такое](%D0%9A%D0%BE%D0%BD%D1%81%D0%BF%D0%B5%D0%BA%D1%82%20%E2%80%94%202.%20SEO%20%E2%80%94%20%D1%87%D1%82%D0%BE%20%D1%8D%D1%82%D0%BE%20%D1%82%D0%B0%D0%BA%D0%BE%D0%B5.md))
- Упоминания бренда
- Поведенческие факторы: CTR сниппета в выдаче и время на странице

## Сниппеты и поведение

Сниппет = «витрина» в выдаче. Два способа его улучшать:

1. **Наполнить** — точный ключ в title, выгода в description
2. **Разметить** — schema.org: Article, Product, BreadcrumbList, FAQPage, Review

```html
<script type="application/ld+json">
{
  "@context": "https://schema.org",
  "@type": "Product",
  "name": "Смартфон Xiaomi Redmi 12",
  "offers": { "@type": "Offer", "price": "12990", "priceCurrency": "RUB" }
}
</script>
```

## Ловушки (переоптимизация)

- Ключевой спам в тексте («купить купить купить») — минус
- Title с 10 ключами — некликабелен → минус
- Скрытый текст / `display:none` — чёрное SEO, фильтры
- Дубли текстов на разных страницах — минус; писать уникальный текст под каждый кластер

## Термины

| Термин | Определение |
|--------|-------------|
| Релевантность | Степень соответствия страницы запросу |
| Сниппет | Блок ссылки в выдаче: title + description + URL |
| Каннибализация | Конкуренция страниц одного сайта за один запрос |
| LSI-слова | Семантически близкие слова, «усиливающие» текст |
| Schema.org | Словарь разметки для расширенных сниппетов |
| Анкор | Текст ссылки, ведущей на страницу |
| Кластер запросов | Группа близких запросов под одну страницу |
