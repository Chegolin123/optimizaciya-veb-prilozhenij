## Что такое продвижение сайта

**Продвижение (раскрутка) сайта** — комплекс мероприятий по привлечению целевых посетителей на сайт и увеличению конверсии. Цель проста: сайт существует, но без трафика он бесполезен — продвижение превращает его в инструмент бизнеса.

## Виды трафика

| Вид | Откуда приходит | Стоимость |
|-----|-----------------|-----------|
| Органический (SEO) | Выдача поисковых систем | Дёшево, но медленно; нужен постоянный труд |
| Платный (контекст) | Объявления Яндекс Директ / Google Ads | Дорого, но сразу |
| Прямой | Закладки, ручной ввод адреса | Растёт с известностью бренда |
| Ссылочный | Ссылки с других сайтов | Зависит от площадки |
| Социальный (SMM) | Посты, сообщества | Средняя |

## Основные каналы продвижения

**SEO** — комплекс мер по повышению позиций в результатах поиска по запросам (определение из презентации 1.1).

**Бесплатные методы раскрутки** (из презентации 1.1): регистрация в поисковиках, работа над контентом, почтовая рассылка, каталоги и рейтинги, обмен текстовыми ссылками, баннерные сети, доски объявлений, СМИ, обмен ссылками с тематическими сайтами, форумы.

## Позиции, поведенческие факторы, конверсия

- **Позиция** — место сайта в выдаче по конкретному запросу. Топ-3 получает основную долю кликов.
- **Поведенческие факторы** — как ведут себя посетители: время на сайте, глубина просмотра, отказы, возвраты. Хорошая поведенка → поисковик поднимает позиции; плохая → опускает.
- **Конверсия** — доля визитов, в которых посетитель совершил целевое действие (покупка, заявка, звонок). «Одинаково заявки контекст и SEO» — продвижение можно сравнивать по конверсии, не только по трафику.

## Сервисы для проверки и управления

| Сервис | Что делает |
|--------|------------|
| Яндекс.Вебмастер | Проверка индексации, sitemap.xml, robots.txt, ошибки, поведение |
| Google Search Console | То же для Google |
| Яндекс.Метрика / Google Analytics | Посещаемость, источники, поведение, конверсии |
| Wordstat / Keyword Planner | Подбор ключевых слов, частотность |

## Планирование продвижения

1. **Цели** — добиться N заявок/мес., N посетителей/день
2. **Семантическое ядро** — какие запросы продвигаем (см. [Конспект — 15. Повышение релевантности](%D0%9A%D0%BE%D0%BD%D1%81%D0%BF%D0%B5%D0%BA%D1%82%20%E2%80%94%2015.%20%D0%9F%D0%BE%D0%B2%D1%8B%D1%88%D0%B5%D0%BD%D0%B8%D0%B5%20%D1%80%D0%B5%D0%BB%D0%B5%D0%B2%D0%B0%D0%BD%D1%82%D0%BD%D0%BE%D1%81%D1%82%D0%B8.md))
3. **Структура и контент** — страницы под каждый запрос
4. **Техническая оптимизация** — скорость, дубли, битые ссылки, индексация ([Конспект — 11-12. Устранение технических ошибок](%D0%9A%D0%BE%D0%BD%D1%81%D0%BF%D0%B5%D0%BA%D1%82%20%E2%80%94%2011-12.%20%D0%A3%D1%81%D1%82%D1%80%D0%B0%D0%BD%D0%B5%D0%BD%D0%B8%D0%B5%20%D1%82%D0%B5%D1%85%D0%BD%D0%B8%D1%87%D0%B5%D1%81%D0%BA%D0%B8%D1%85%20%D0%BE%D1%88%D0%B8%D0%B1%D0%BE%D0%BA.md), [Конспект — 10. ЧПУ, Robots.txt, карта сайта](%D0%9A%D0%BE%D0%BD%D1%81%D0%BF%D0%B5%D0%BA%D1%82%20%E2%80%94%2010.%20%D0%A7%D0%9F%D0%A3%2C%20Robots.txt%2C%20%D0%BA%D0%B0%D1%80%D1%82%D0%B0%20%D1%81%D0%B0%D0%B9%D1%82%D0%B0.md))
5. **Исходящие ссылки** — ссылочная масса с тематических площадок
6. **Поведческие факторы** — юзабилити, удобство, быстрота загрузки ([Конспект — 4. Юзабилити-аудит](%D0%9A%D0%BE%D0%BD%D1%81%D0%BF%D0%B5%D0%BA%D1%82%20%E2%80%94%204.%20%D0%AE%D0%B7%D0%B0%D0%B1%D0%B8%D0%BB%D0%B8%D1%82%D0%B8-%D0%B0%D1%83%D0%B4%D0%B8%D1%82.md))
7. **Аналитика** — отслеживание через Яндекс.Метрику/Вебмастер каждую неделю

## Почему одних регистраций недостаточно

Просто «подать сайт в поисковики» мало — сайт должен быть найден и оценён. Процесс сложный: надо заработать доверие поисковика (тИЦ / авторитетность) контентом и внешними ссылками, поддерживать качество (отсутствие ошибок) и поведение (удобство) — поэтому продвижение это постоянная работа.

## Термины

| Термин | Определение |
|--------|-------------|
| SEO | Поисковая оптимизация — рост позиций в органической выдаче |
| Органический трафик | Посетители из бесплатной поисковой выдачи |
| Позиция | Место сайта в выдаче по запросу |
| Поведенческие факторы | Время на сайте, глубина, отказы, возвраты посетителей |
| Конверсия | Доля визитов с целевым действием |
| Семантическое ядро | Набор запросов, под которые оптимизируют сайт |
