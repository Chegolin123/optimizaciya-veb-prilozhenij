# Конспект — 7-8. Способы ускорения загрузки сайтов

> Тема занятия из [таблицы курса](https://docs.google.com/spreadsheets/d/1mLdR4r9jjsBcKdaG77887BA6OdZc_tCmDNlfhJGdJfk/edit?gid=187801412).

## Метрики скорости

| Метрика | Что измеряет | Хорошее значение |
|---------|--------------|------------------|
| TTFB | Время до первого байта от сервера | < 0,6 с |
| FCP | Первая отрисовка контента | < 1,8 с |
| LCP | Крупнейший элемент отрисован (главное) | < 2,5 с |
| CLS | Смещение контента при загрузке | < 0,1 |
| TTI | Время до интерактивности | < 3,8 с |

**Why:** >1 с задержки = −7% конверсий (исследования Amazon/Google). Скорость — фактор ранжирования.

## Почему сайт тормозит

1. **Тяжёлые изображения** — мегабайты JPEG на превью 300×200
2. **Сервер отвечает медленно** — TTFB из-за БД или хостинга (см. [Конспект — 3. Оптимизация серверной части](%D0%9A%D0%BE%D0%BD%D1%81%D0%BF%D0%B5%D0%BA%D1%82%20%E2%80%94%203.%20%D0%9E%D0%BF%D1%82%D0%B8%D0%BC%D0%B8%D0%B7%D0%B0%D1%86%D0%B8%D1%8F%20%D1%81%D0%B5%D1%80%D0%B2%D0%B5%D1%80%D0%BD%D0%BE%D0%B9%20%D1%87%D0%B0%D1%81%D1%82%D0%B8.md))
3. **Много запросов** — 100+ HTTP-запросов, включая мелочь (иконки, шрифты)
4. **Нет кэша** — браузер каждый раз тянет всё заново
5. **Блокирующий CSS/JS в `<head>`** — страница ждёт, пока загрузятся файлы
6. **Наружные виджеты** — метрики, чаты, кнопки соцсетей тормозят загрузку
7. **Неиспользованные шрифты** — несколько family в 3–4 начертаниях
8. **Ресурсы без сжатия** — незаминифицированные CSS/JS, нет gzip/Brotli

## Способы ускорения

### Изображения (самый большой выигрыш)

- **Форматы:** WebP/AVIF вместо JPEG/PNG (−25–35% при том же качестве)
- **Размеры:** thumbnails, а не оригинал — рисунок 3840×2400 выводится 600 px
- **Сжатие:** онлайн-инструменты (Squoosh, TinyPNG), `imagemagick`
- **Ленивая загрузка (lazy loading):** `loading="lazy"` — грузятся только в вьюпорте
- **`srcset`/`sizes`:** браузер выбирает подходящий файл под экран
- **Спрайты / иконочные шрифты:** один запрос вместо 30

### CSS / JS

- **Минификация** — убрать пробелы/комментарии
- **Объединение** — 1 CSS + 1 JS вместо десятка файлов
- **Отложенная загрузка:** `<script defer>`, `<script async>`; `async` для независимых скриптов
- **Удалить неиспользуемый код** — библиотека ради одной функции

### Браузерный кэш и CDN

- **Cache-Control / ETag:** кешировать статику на год, HTML — коротко
- **CDN:** отдача из ближайшей к пользователю точки (Cloudflare и аналоги)

### Серверная часть

- **gzip/Brotli:** сжатие текстовых ответов (бывает −70% объёма)
- **HTTP/2:** мультиплексирование — много ресурсов по одному соединению
- **Убрать лишние редиректы:** цепочки 301 добавляют round-trip'ы

### Приоритеты

- **Критический CSS** — инлайн в `<head>` (быстрая первая отрисовка)
- **Preload / Prefetch:** для шрифтов и ключевых ресурсов

## Инструменты измерения

| Инструмент | Что показывает |
|------------|----------------|
| Google PageSpeed Insights | Оценка 0–100, метрики LCP/CLS, рекомендации |
| GTmetrix | Waterfall загрузки всех ресурсов |
| WebPageTest | Тесты из разных локаций/скоростей, waterfall |
| Lighthouse (DevTools) | Performance-аудит |
| Yandex.Метрика → скорость | Фактические данные по посетителям сайта |

## Термины

| Термин | Определение |
|--------|-------------|
| LCP | Largest Contentful Paint — время отрисовки крупнейшего элемента |
| TTFB | Time To First Byte — время до первого байта от сервера |
| CLS | Cumulative Layout Shift — смещение контента при загрузке |
| Lazy loading | Отложенная загрузка ресурсов вне видимой области |
| Cache-Control | Заголовок, управляющий кэшированием ответа браузером |
| CDN | Сеть доставки контента из ближайших к пользователю узлов |
| Критический CSS | CSS, необходимый для первой отрисовки выше сгиба |
| Waterfall | Диаграмма загрузки ресурсов по времени |
