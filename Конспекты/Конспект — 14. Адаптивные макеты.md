# Конспект — 14. Адаптивные макеты

> Тема занятия из [таблицы курса](https://docs.google.com/spreadsheets/d/1mLdR4r9jjsBcKdaG77887BA6OdZc_tCmDNlfhJGdJfk/edit?gid=187801412). Связанная работа: Практическая работа 2-3 (29.09.2026) — ЛР №2 мобильная оптимизация и адаптивность.

## Проблема

Одна и та же страница открывается на мониторе 1920 px, планшете 768 px и телефоне 360 px. Фиксированная вёрстка (см. [Конспект — 1.1. Основы разработки web-приложения](%D0%9A%D0%BE%D0%BD%D1%81%D0%BF%D0%B5%D0%BA%D1%82%20%E2%80%94%201.1.%20%D0%9E%D1%81%D0%BD%D0%BE%D0%B2%D1%8B%20%D1%80%D0%B0%D0%B7%D1%80%D0%B0%D0%B1%D0%BE%D1%82%D0%BA%D0%B8%20web-%D0%BF%D1%80%D0%B8%D0%BB%D0%BE%D0%B6%D0%B5%D0%BD%D0%B8%D1%8F.md)) на телефоне не работает. Решение — адаптивная вёрстка (responsive).

## Три подхода

| Подход | Суть | Статус |
|--------|------|--------|
| Отдельный мобильный сайт (`m.site.ru`) | Робот определяет устройство и редиректит | Устарел; Яндекс рекомендует адаптив |
| Адаптивный (responsive) | Один HTML, разный CSS по ширине экрана | **Основной стандарт** |
| Мобильное приложение | Offline, но требует установки | Не для сайта |

Главное преимущество адаптива: один URL → нет дублей, весь SEO-вес на одну страницу (см. [Конспект — 11-12. Устранение технических ошибок](%D0%9A%D0%BE%D0%BD%D1%81%D0%BF%D0%B5%D0%BA%D1%82%20%E2%80%94%2011-12.%20%D0%A3%D1%81%D1%82%D1%80%D0%B0%D0%BD%D0%B5%D0%BD%D0%B8%D0%B5%20%D1%82%D0%B5%D1%85%D0%BD%D0%B8%D1%87%D0%B5%D1%81%D0%BA%D0%B8%D1%85%20%D0%BE%D1%88%D0%B8%D0%B1%D0%BE%D0%BA.md)).

## Отзывчивая сетка

Вместо фиксированных пикселей — относительные единицы и множители:

```css
.container {
  max-width: 1200px;
  margin: 0 auto;
  padding: 0 16px;
}
.grid {
  display: grid;
  grid-template-columns: repeat(auto-fill, minmax(280px, 1fr));
  gap: 16px;
}
```

`repeat(auto-fill, minmax(280px, 1fr))` — сколько колонок влезет, столько и будет: на мониторе 4, на телефоне 1.

## Viewport

Без метатега мобильный браузер «притворяется» монитором 980 px и масштабирует страницу:

```html
<meta name="viewport" content="width=device-width, initial-scale=1">
```

## Media queries и брейкпоинты

```css
/* Mobile first: базовый стиль для узкого экрана */
body { font-size: 16px; }

/* Планшет */
@media (min-width: 768px) { .grid { grid-template-columns: 1fr 1fr; } }

/* Десктоп */
@media (min-width: 1200px) { .grid { grid-template-columns: 1fr 1fr 1fr 1fr; } }
```

Типовые брейкпоинты: 320 (моб), 480, 768 (планшет), 1024, 1200 (десктоп). Точные числа зависят от проекта — брейкпоинты ставят **по контенту**: расширяют окно, пока вёрстка не начинает выглядеть плохо, и фиксируют эту ширину.

## Единицы измерения

| Единица | Относительно чего | Где применять |
|---------|-------------------|---------------|
| `px` | Абсолют | Границы, мелкие детали |
| `%` | Родителя | Ширины блоков |
| `rem` | Размер шрифта корня (по умолчанию 16px) | Отступы, типографика — масштабируется при изменении настроек браузера |
| `em` | Родительский шрифт | Локальные отступы |
| `vw`/`vh` | Ширина/высота вьюпорта | Полноэкранные блоки |
| `clamp()` | Между минимумом и максимумом | `font-size: clamp(16px, 4vw, 24px)` |

## Изображения на адаптиве

- `max-width: 100%` + `height: auto` — картинка не вылезает за блок
- `srcset`/`sizes` — разные файлы под экраны (см. [Конспект — 13. Оптимизация изображений](%D0%9A%D0%BE%D0%BD%D1%81%D0%BF%D0%B5%D0%BA%D1%82%20%E2%80%94%2013.%20%D0%9E%D0%BF%D1%82%D0%B8%D0%BC%D0%B8%D0%B7%D0%B0%D1%86%D0%B8%D1%8F%20%D0%B8%D0%B7%D0%BE%D0%B1%D1%80%D0%B0%D0%B6%D0%B5%D0%BD%D0%B8%D0%B9.md))
- Не грузить десктопные 4K-фото на мобильном — экономим трафик
- Картинки товаров в каталоге — квадратные блоки с `object-fit: cover`, чтобы сетка не «прыгала»

## Мобильные особенности (сверх вёрстки)

- **Touch-цели:** кнопки/ссылки ≥ 44×44 px (не меньше возможности нажать пальцем)
- **Меню-бургер:** навигация скрывается под кнопкой
- **Формы:** нужные клавиатуры (`type="tel"`, `inputmode="numeric"`), крупные поля
- **Таблицы:** горизонтальный скролл или переверстка в карточки
- **Popup'ы:** на мобильном — на весь экран, липкая корзина/звонок
- **Скорость:** мобильный трафик часто медленнее — оптимизация изображений и шрифтов критична

## Проверка адаптивности

1. DevTools → режим устройства (Ctrl+Shift+M) — разные разрешения
2. Реальный телефон (не только эмуляция)
3. Плотность пикселей, тёмная тема
4. Горизонтальная ориентация
5. PageSpeed → раздел «Мобильные устройства»

## Термины

| Термин | Определение |
|--------|-------------|
| Responsive / отзывчивая вёрстка | Верстка, подстраивающаяся под ширину экрана |
| Viewport | Видимая область страницы; метатег задаёт масштаб |
| Media query | Условие в CSS: применяется при подходящем экране |
| Брейкпоинт | Ширина, на которой меняется раскладка |
| Mobile first | Стратегия: сначала стили для мобильных, затем усложнение |
| Touch-цель | Элемент интерфейса достаточного размера для касания |
| Fluid grid | Сетка на относительных единицах (auto-fill/minmax) |
