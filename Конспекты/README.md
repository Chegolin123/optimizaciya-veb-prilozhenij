## Как пользоваться

Каждый конспект — отдельный файл в формате Markdown. Внутри конспектов ссылки ведут
на связанные заметки этого же курса. Заголовок файла содержит номер темы из
[таблицы курса](https://docs.google.com/spreadsheets/d/1mLdR4r9jjsBcKdaG77887BA6OdZc_tCmDNlfhJGdJfk/edit?gid=187801412).
